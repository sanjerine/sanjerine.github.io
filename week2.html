Variables & Types

In the lecture, we learned that all data is stored as bits. Python hides this complexity, but understanding what's happening underneath helps you become a better programmer.

Pythonvariables hold data

print(age)          # 19
print(type(age))     # <class 'int'>
print(type(name))    # <class 'str'>
print(type(temperature)) # <class 'float'>

💡 Connection to the lecture

Remember from class: integers are stored in binary, text uses ASCII/Unicode, and decimals use floating-point notation. Python's types match these exactly:

  • int → stored as binary integer (like two's complement)
  • str → stored as Unicode characters (each character = a number)
  • float → stored as IEEE 754 floating-point (sign + exponent + mantissa)
  • bool → stored as a single bit (True = 1, False = 0)

Binary & Hex in Python

Python has built-in tools to convert between decimal, binary, and hexadecimal — the same conversions we practised by hand in class.

Pythonbuilt-in conversions
# Decimal to binary
print(bin(13))      # 0b1101

# Decimal to hexadecimal

# Binary to decimal

# Hex to decimal
print(0xff)         # 255

# You can also use int() with a base

print(int("ff", 16))     # 255 (base 16 = hex)
Notice the prefixes: 0b means binary, 0x means hexadecimal. These are the same prefixes from the lecture slides!

Build Your Own Binary Converter

Instead of using bin(), let's write the algorithm from the lecture (Figure 1.15) ourselves. This is real programming — turning an algorithm into code.

📋 The algorithm (from lecture)

To convert a decimal number to binary:

  1. Divide the number by 2, record the remainder
  2. Keep dividing the quotient by 2, recording remainders
  3. Read the remainders from bottom to top = binary number
Pythonthe algorithm as code
def to_binary(number):
    if number == 0:
        return "0"

    bits = ""     # We'll build the binary string here

    while number > 0:
        remainder = number % 2    # % gives the remainder
        bits = str(remainder) + bits  # Add to the LEFT
        number = number // 2   # // gives integer division

    return bits

# Test it!
print(to_binary(13))   # Should print: 1101
print(to_binary(19))   # Should print: 10011
print(to_binary(255))  # Should print: 11111111
Output
1101 10011 11111111
New Python concepts here: % (modulo) gives the remainder after division. // (floor division) divides and rounds down. while repeats a block of code as long as a condition is true. def creates a reusable function.

ASCII & Unicode

In the lecture, we learned that text is stored as numbers. Python lets us see this directly.

Pythontext ↔ numbers
# ord() gives the number for a character
print(ord("A"))    # 65
print(ord("a"))    # 97
print(ord("0"))    # 48  (the character "0", not the number!)

# chr() gives the character for a number
print(chr(65))     # A
print(chr(72))     # H

# Encode a full word
word = "Hello"
for char in word:
    print(f"'{char}' = {ord(char)} = {bin(ord(char))}")
Output
'H' = 72 = 0b1001000 'e' = 101 = 0b1100101 'l' = 108 = 0b1101100 'l' = 108 = 0b1101100 'o' = 111 = 0b1101111

🌏 Unicode — beyond English

ASCII only covers English (128 characters). Unicode covers every language. Python handles Unicode natively:

Pythonunicode in action
# Chinese characters have much larger code numbers
print(ord("你"))    # 20320
print(ord("好"))    # 22909
print(hex(ord("你")))  # 0x4f60

# This is why we need more than 8 bits for text!
# ASCII: 7 bits = 128 characters (English only)
# Unicode: up to 21 bits = 1,114,112 characters (all languages)

print(chr(128522))  # 😊 even emoji have Unicode numbers!

Two's Complement in Python

Let's verify the two's complement examples from the lecture with actual code.

Pythontwo's complement by hand
def twos_complement(number, bits=4):
    """Convert a number to its two's complement binary string."""
    if number >= 0:
        # Positive: just convert to binary, pad with zeros
        binary = bin(number)[2:]  # remove '0b'
        return binary.zfill(bits)  # pad with zeros
    else:
        # Negative: invert bits and add 1
        positive = bin(abs(number))[2:].zfill(bits)
        # Flip every bit
        flipped = "".join("1" if b == "0" else "0" for b in positive)
        # Add 1
        result = bin(int(flipped, 2) + 1)[2:]
        return result[-bits:]  # keep only the last N bits

# Test with examples from the lecture slides
print(f" 5 = {twos_complement(5)}")    # 0101
print(f"-5 = {twos_complement(-5)}")   # 1011
print(f"-6 = {twos_complement(-6)}")   # 1010
print(f"-3 = {twos_complement(-3)}")   # 1101
Output
5 = 0101 -5 = 1011 -6 = 1010 -3 = 1101
Pythonverifying addition from the slides
# From slide: 5 + (-5) should equal 0
a = "0101"  # 5
b = "1011"  # -5 in two's complement

# Add them as binary numbers
result = bin(int(a, 2) + int(b, 2))[2:]
print(f"{a} + {b} = {result}")
# Output: 0101 + 1011 = 10000
# Discard the carry bit → 0000 = 0 ✓
