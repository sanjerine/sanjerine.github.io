## What is Python?

A **programming language** lets you give instructions to a computer by typing text. You type a command, and the computer does exactly what you asked.

**Python** is one of the most popular programming languages. It is easy to read because it looks a bit like English. Think of Python as a calculator that can also work with text.

## Print and comments

`print()` is a built-in command that shows output on the screen.

- Text needs **quotes**: `print("hello")`
- Numbers do **not** need quotes: `print(42)`
- You can print maths: `print(3 + 5)`

A **comment** starts with `#`. Python skips everything after `#` on that line. Comments are notes for you and other people reading your code.

```python
# This is a comment — Python skips it
print("CITX0001")   # prints the unit code
print(100)           # prints the number 100
print(50 + 50)       # prints 100 (the result of 50 + 50)
```

## Variables

A **variable** is like a labelled box that holds a value. You create one with `=`.

In Python, `=` means **"store this value"**. It does not mean "equals" like in maths.

```python
name = "Alice"
age = 19
print(name)
print(age)
```

You can **change** a variable by giving it a new value:

```python
score = 10
print(score)

score = 25
print(score)
```

The second `print` shows `25` because we changed `score`.

### Naming rules

- Names can have letters, numbers, and underscores (`_`).
- Names **cannot** start with a number. `2name` does not work.
- Names **cannot** have spaces. Use underscores instead: `student_id`, not `student id`.
- Capital letters matter: `Age` and `age` are two different variables.

## Types: how Python stores data

Every value in Python has a **type**. A type tells Python what kind of data it is. There are four main types:

| Type    | What it stores       | Example            |
| ------- | -------------------- | ------------------ |
| `int`   | Whole numbers        | `19`, `-3`, `0`    |
| `float` | Decimal numbers      | `3.14`, `-0.5`     |
| `str`   | Text (called a "string") | `"hello"`, `"42"` |
| `bool`  | True or false        | `True`, `False`    |

Use `type()` to check the type of a value:

```python
print(type(19))
print(type(3.14))
print(type("hello"))
print(type(True))
```

### Watch out: `"19"` vs `19`

Quotes change the meaning. `"19"` is **text** (a string). `19` is a **number** (an integer). This is important when you combine values:

```python
print(5 + 3)       # 8 — adds the numbers
print("5" + "3")   # "53" — joins the text together
```

`"5" + "3"` does not give `8`. It joins the two pieces of text into `"53"`.

<Callout tone="info" title="Lecture connection">

- `str` — text, where each character has a number (Unicode code point).
- `float` — decimal numbers stored using IEEE 754.
- `bool` — true or false, like a single bit: `True` = 1, `False` = 0.

## Arithmetic in Python

Python can do maths with these operators:

| Operator | What it does           | Example    | Result |
| -------- | ---------------------- | ---------- | ------ |
| `+`      | Add                    | `7 + 3`    | `10`   |
| `-`      | Subtract               | `7 - 3`    | `4`    |
| `*`      | Multiply               | `7 * 3`    | `21`   |
| `/`      | Divide                 | `7 / 3`    | `2.33…`|
| `//`     | Divide and round down  | `7 // 3`   | `2`    |
| `%`      | Remainder              | `7 % 3`    | `1`    |
| `**`     | Power                  | `2 ** 3`   | `8`    |

Two of these are very important for this unit:

- `//` is **integer division**. It divides and removes the decimal part. `7 // 3` gives `2`, not `2.33`.
- `%` is **modulo**. It gives the leftover (remainder) after division. `7 % 3` gives `1`, because 7 = 2 x 3 + **1**.

We need `//` and `%` because they are the steps in the lecture algorithm for converting decimal to binary.

### Worked example: decimal 13 to binary

The lecture algorithm says: keep dividing by 2, write down the remainder each time, then read the remainders from bottom to top.

```python
print(13 % 2)    # 1  (remainder)
print(13 // 2)   # 6  (result of the division — use this next)

print(6 % 2)     # 0
print(6 // 2)    # 3

print(3 % 2)     # 1
print(3 // 2)    # 1

print(1 % 2)     # 1
print(1 // 2)    # 0  (result is 0, so we stop)
```

Read the remainders from bottom to top: **1, 1, 0, 1**. So 13 in binary is `1101`. You can check: `bin(13)` gives `0b1101`.

## Binary and hexadecimal in Python

Python has built-in tools to convert between number systems:

```python
print(bin(13))          # '0b1101'  — binary
print(hex(255))         # '0xff'    — hexadecimal
```

The `0b` at the start means "this is a binary number". The `0x` at the start means "this is a hexadecimal number". You can also type these directly:

```python
print(0b1101)           # 13
print(0xff)             # 255
```

To convert a text string of digits back to a decimal number, use `int()` with a second value that says what base the digits are in:

```python
print(int("1101", 2))   # 13  — reads "1101" as base 2 (binary)
print(int("ff", 16))    # 255 — reads "ff" as base 16 (hex)
```

## Strings and text

A **string** is a piece of text inside quotes. You can join two strings together with `+`:

```python
first = "Ada"
last = "Lovelace"
full = first + " " + last
print(full)
```

Use `len()` to count how many characters are in a string:

```python
print(len("CITX0001"))   # 8
```

### Mixing strings and numbers

You **cannot** join a string and a number with `+`. This gives an error:

```python
# This gives an error:
# print("Age: " + 19)
```

You need to turn the number into text first using `str()`:

```python
age = 19
print("Age: " + str(age))
```

## ASCII and Unicode: text as numbers

Computers store everything as numbers, including text. Each character gets a number called a **code point**. The system that decides which number goes with which character is called an **encoding**.

**ASCII** covers basic English letters (A–Z, a–z), digits (0–9), and some symbols. **Unicode** covers every language in the world, plus symbols and emoji.

Python has two useful functions for this:

- `ord("A")` — give it a character, it gives you the code point (a number).
- `chr(65)` — give it a code point, it gives you the character.

```python
print(ord("A"))     # 65
print(ord("a"))     # 97
print(ord("0"))     # 48
```

You can then see how that number looks in binary:

```python
code = ord("A")
print(code)         # 65
print(bin(code))    # 0b1000001
```

So the letter "A" is stored as the number 65. In binary, that is `1000001`.

### Unicode: beyond English

Unicode includes characters from every language, and emoji too:

```python
print(ord("你"))       # 20320
print(hex(ord("你")))  # 0x4f60
print(chr(128522))     # 😊
```

## Putting it together

Now let's use everything you learned in one mini-project: a **character inspector**. You give it a character, and it shows the code point, binary, and hexadecimal.

```python
# Character inspector
character = "A"

code_point = ord(character)
binary = bin(code_point)
hexadecimal = hex(code_point)

print("Character: " + character)
print("Code point: " + str(code_point))
print("Binary: " + binary)
print("Hex: " + hexadecimal)
```

This uses only things you learned today: variables, `ord()`, `bin()`, `hex()`, `str()`, and joining strings with `+`.
