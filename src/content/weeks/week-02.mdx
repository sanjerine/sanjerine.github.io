## Variables and types

Python variables are names bound to values.

```python
age = 19
name = "Alice"
temperature = 36.5
is_student = True

print(age)
print(type(age))
print(type(name))
print(type(temperature))
print(type(is_student))
```

Lecture connection:

- `int` values are binary integers.
- `str` values are sequences of Unicode code points.
- `float` values are IEEE 754 floating-point.
- `bool` maps to logical true/false states.

## Binary and hexadecimal in Python

Python has built-in conversion helpers:

```python
print(bin(13))         # 0b1101
print(hex(255))        # 0xff
print(0b1101)          # 13
print(0xff)            # 255
print(int("1101", 2)) # 13
print(int("ff", 16))  # 255
```

<Callout tone="info" title="Reminder">

`0b` means binary literal. `0x` means hexadecimal literal.

</Callout>

## Build your own decimal-to-binary converter

Instead of calling `bin()`, implement the repeated-division algorithm from lectures.

```python
def to_binary(number):
    if number == 0:
        return "0"

    bits = ""

    while number > 0:
        remainder = number % 2
        bits = str(remainder) + bits
        number = number // 2

    return bits


print(to_binary(13))
print(to_binary(19))
print(to_binary(255))
```

Expected output:

```text
1101
10011
11111111
```

## ASCII and Unicode

Text is represented as numbers. Python exposes this directly with `ord()` and `chr()`.

```python
print(ord("A"))
print(ord("a"))
print(ord("0"))

print(chr(65))
print(chr(72))

word = "Hello"
for char in word:
    print(f"'{char}' = {ord(char)} = {bin(ord(char))}")
```

Unicode extends beyond ASCII:

```python
print(ord("你"))
print(ord("好"))
print(hex(ord("你")))
print(chr(128522))
```

## Two's complement with Python

Use code to verify the binary examples discussed in class.

```python
def twos_complement(number, bits=4):
    if number >= 0:
        binary = bin(number)[2:]
        return binary.zfill(bits)

    positive = bin(abs(number))[2:].zfill(bits)
    flipped = "".join("1" if b == "0" else "0" for b in positive)
    result = bin(int(flipped, 2) + 1)[2:]
    return result[-bits:]


print(f" 5 = {twos_complement(5)}")
print(f"-5 = {twos_complement(-5)}")
print(f"-6 = {twos_complement(-6)}")
print(f"-3 = {twos_complement(-3)}")
```

## Challenge: overflow detector

Build a tool that reports whether integer addition fits inside an N-bit two's complement range.

```python
def check_overflow(a, b, bits):
    minimum = -(2 ** (bits - 1))
    maximum = (2 ** (bits - 1)) - 1

    result = a + b

    print(f"Range for {bits} bits: {minimum} to {maximum}")
    print(f"{a} + {b} = {result}")

    if result < minimum or result > maximum:
        print("OVERFLOW")
    else:
        print("No overflow")


check_overflow(5, 4, 4)
check_overflow(3, 2, 4)
check_overflow(-3, -6, 4)
```
